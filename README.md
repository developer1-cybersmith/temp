# Vyavsay Assist

WhatsApp AI sales copilot for small businesses (first vertical: used cars).

- `vyavsay-v2/`: the Python/FastAPI rebuild (active). Start with `vyavsay-v2/docs/START-HERE.md`.
- `backend/`, `frontend/`: legacy app, read-only reference. The frontend is reused as-is; its API contract is fixed.
- `docs/production-plan/`: audit of the legacy app and the owner decisions.
- `CLAUDE.md`, `SKILL.md`: project instructions and the ChatSyncs API guide.
